# 🐍 Python Fundamentals & Analytical Exercises

A collection of core Python programming tasks demonstrating data structures, algorithmic logic, and clean code practices.

---

### 📌 Topics Covered
- **Lists & Aggregations:** Performing custom statistical computations (min, max, average) without relying on external libraries.
- **Data Filtering & Deduplication:** Array manipulation, element sorting, and finding overlapping elements across collections.
- **Sets Operations:** Finding common intersections and removing duplicate identifiers efficiently.

---

### 🛠️ Technologies
- **Language:** Python 3.x
- **Concepts:** Data Structures (Lists, Sets), Control Flow, String Formatting.
